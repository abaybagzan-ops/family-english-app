# Отбасылық ағылшын — семейное приложение для английского

Самостоятельный проект. Не связан с подготовкой к НИШ.

Интерфейс на казахском, учебный материал на английском. Первая версия охватывает только слова, грамматику и чтение коротких текстов.

## Как запустить

Сборка, сервер и интернет не нужны.

- **Самый простой способ:** открыть `index.html` двойным щелчком в браузере (Chrome, Edge, Firefox, Safari).
- **Через локальный сервер** (удобно, чтобы открыть с телефона в той же сети):

  ```bash
  cd family-english-app
  python3 -m http.server 8000
  ```

  Затем открыть `http://localhost:8000`.

Прогресс хранится в `localStorage` браузера под ключом `familyEnglishApp.v1`. Он привязан к устройству и браузеру и на другое устройство не переносится.

## Структура

```
index.html                 оболочка, порядок подключения скриптов

js/content/stages.js       ступени, старые интересы (v1), НАСТРОЙКИ ПИЛОТА (FEA.settings)
js/content/interests.js    направления интересов, уточнения, типы учебных действий (v2)
js/content/interest-variants.js  варианты уроков по интересам: роль, задача, решение
js/content/helpers.js      конструкторы заданий: choice / typed / order / match / word
js/content/diagnostic.js   15 вопросов стартовой диагностики (+ вопросы для повторения)
js/content/lessons-stage0..3.js   первые уроки ступеней (order 1)
js/content/lessons-stage0b..3b.js вторые уроки ступеней (order 2)
js/content/missions.js     квест-слой: миссии, «аламын»-результаты, истории для сложных тем, подсказки
js/storage.js              localStorage: профили, сброс
js/engine.js               логика: сборка урока, проверка, повторение, рекомендации
js/ui.js                   создание элементов, окно подтверждения
js/app.js                  экраны
tools/validate-content.js  проверка учебных данных (node)
```

## Учебная модель

- **4 внутренние ступени:** «Нөлден бастау», «Бастауыш», «Негізгі», «Орта және одан жоғары». Обозначения A0–B2 в `cefrHint` — только предварительный ориентир, а не сертификация.
- **У каждого навыка своя ступень.** На каждую ступень по 2 урока на навык (слова, грамматика, чтение) — всего 24 урока-миссии.
- **Семейные профили:** Әке, Ана (болжамды A0), Бағжан (B1–B2), Айару (A2), Ай-Батыр, Ай Сұлтан, Айбар (A1) и «Басқа профиль». Уровень задаёт стартовую ступень по всем навыкам; это ориентир, не оценка. Выбор существующего профиля открывает его, дубликат не создаётся.
- **Диагностика ничего не меняет сама:** показывает предложение по каждому навыку, ученик принимает его кнопкой «Қабылдау».
- **Урок-миссия строится так:**
  1. миссия: сцена и практический результат («... аламын»);
  2. разминка (вспоминание) и 1–2 повтора, у которых наступил срок;
  3. для сложных тем — история: сценка → правило в 2–3 предложениях → пример с разбором частей → попытка ученика;
  4. цель, примеры, новые слова;
  5. задания от узнавания к вспоминанию и применению;
  6. текст и задания по нему.

  Основных заданий 4–6. При ошибке — подсказка и вторая попытка (в диагностике — нет). В точность идёт первая попытка; задание с ошибкой возвращается в повторение на следующий день.
- **Интересы** (до трёх направлений, порядок = приоритет, плюс уточнение «что нравится»). Интерес меняет роль ученика, задачу и способ решения, а не только слова: в уроке может быть вариант `v-<направление>` с ролью, миссией и двумя заданиями (решение по материалу + использование целевой формы). Подбор (`FEA.engine.pickVariant`): вариант-действие для направления → вариант с любимым типом действия (тема честно названа другой) → только текст на тему → общий вариант с пометкой. Пустой выбор допустим. Ступень, порядок уроков, основные задания и ключи ответов от интереса не зависят. Старое поле `interest` читается и не перезаписывается. Сейчас варианты есть в 4 уроках: `s2-grammar-2` (пилот, 9 вариантов), `s1-reading-2`, `s2-grammar`, `s0-reading-2` (по 3).
- **Подача интереса** на экране: карточка урока несёт одну метку — «Миссия: роль» (интерес меняет задание), «Тақырып: …» (меняется только текст) или «Жалпы сабақ». На экране выбора у направления видно, в скольких уроках есть роль (`FEA.engine.directionStats`), и реальный пример из урока. Короткие формулировки — `FEA.directionShort` в `js/content/interests.js`; у варианта — поле `task`.
- **Миры (кейіпкерлер әлемі)** — необязательное уточнение направления (`FEA.worlds`, поле варианта `world`, в профиле `interests[].worlds`). В выборе показываются только миры, у которых есть вариант урока (проверяет валидатор). Выбранный мир повышает приоритет своего варианта; варианты остальных миров не закрываются. Варианты с мирами: `s1-reading` (тергеу, спорт, кейіпкерлер — прототип: одна цель «кім / қайда / қашан»), `s1-reading-2` (сиқыр), `s1-grammar-2` (құрылыс).
- **Сөздік** (раздел навигации): собирается из слов уроков (`words`, `themeWords`) функцией `FEA.engine.buildDictionary`; перевод — только из записи слова, глоссарии не берутся. Поиск по английскому и по переводу, повторение карточками; результат повторения — в `profile.vocab`, прогресс уроков он не меняет.
- **Тапсырма түрі «Негізгі / Күрделірек»** (`js/content/challenges.js`) — это сложность задания, не уровень языка и не интерес. У урока с вызовом на экране миссии можно выбрать «Күрделірек»: часть основных заданий заменяется заданиями на ту же цель, где форма не подсказана (слово нужно найти в материале и самому изменить или написать). Пустой выбор — базовая ступень; выбор запоминается для урока в `profile.taskLevel`; ступень профиля, доступ к урокам и прогресс не меняются. Сейчас вызов есть у `s1-grammar` (эталон), `s1-grammar-2`, `s1-words`. Ошибки заданий вызова попадают в обычное повторение (`m|урок|контекст|challenge|n`).
- **Өткенді жаттығу** («Прогресс») — тренировка вопросов повторения из пройденных уроков без записи: расписание, ошибки и прогресс не меняются.
- **«Мен не істей аламын»** на странице прогресса: практические результаты пройденных миссий и следующая миссия по каждому навыку. Без очков, рейтингов и обязательных серий.
- **Персонажи** — только оригинальные (Жарқын Қанат / Bright Wing, город Riverstone, Ellison Creek, а также миры интересов `FEA.worlds`: Алан мен Ая, «Дала кубогы», Түнгі Сілеусін мен Ұшқын, Аспан академиясы, Блок аралы). Персонажи, названия, логотипы и сцены известных франшиз и лиг не используются; реальные спортсмены и организаторы не упоминаются. Ученик может вписать любимого персонажа в «Өз тақырыбым» — название сохраняется в профиле, но готовых текстов о нём нет и приложение их не создаёт.
- **Повторение:** интервалы 1 → 3 → 7 → 14 → 30 дней. Ошибка возвращает вопрос на 1 день. В уроке не больше 2 повторов, в отдельной сессии — до 6.
- **Ступень автоматически не меняется.** Приложение только предлагает «Келесі сатыны байқап көру» («Попробовать следующую ступень»), а решает ученик. Предложение появляется, если урок пройден с точностью от 80% и после него по этому навыку было не меньше 2 верных повторений.
- Все числа в `FEA.settings` — **настройки пробного запуска, а не нормы из исследований.**

## Как добавить урок

1. Добавить объект в нужный `lessons-stageN.js` через `FEA.lessons.push({...})`. Поля:
   - `id`, `stage`, `skill`, `title`, `goal`, `explain[]`, `examples[]`;
   - `words[]` — общеупотребительные слова;
   - `warmup` — задание на разминку;
   - `tasks[]` — основные задания;
   - `order` — порядок урока внутри ступени и навыка;
   - `defaultContext` — общий текст для интересов без своего варианта;
   - `contexts` — любые из `usa`, `mystery`, `sport`, `travel`, `tech`, `nature`, `everyday`: `themeWords`, `text {title, lines, glossary}`, `tasks`;
   - варианты по интересам добавляются в `js/content/interest-variants.js` (`interests`, `mode`, `role`, `label`, `mission`, `textHeading`, `text`, 2 задания; у выбора можно задать `outcomes` — последствие каждого варианта);
   - `review[]` с уникальными `id`;
   - `editorNotes[]` — пометки для редактора, ученику они не показываются.
2. Добавить миссию и практический результат в `js/content/missions.js` (`mission`, `canDo`; для сложной темы — `story`, по желанию `hints`).
3. Запустить проверку:

   ```bash
   node tools/validate-content.js --notes
   ```

## Что требует проверки специалистом

Список выводится командой `node tools/validate-content.js --notes`. Главное:

- **все казахские объяснения**, особенно сопоставления «-мын ↔ am», «...ып жатқан еді ↔ was/were + -ing», «қарамастан ↔ although/despite», «шаршадым ↔ I'm tired», «-ыл/-іл ↔ be + V3», «-рақ/-рек, -нан/-нен ↔ -er, than»;
- тексты миссий, историй и подсказок в `missions.js`;
- переводы gate, clue, barely, afford, haunted, tip и фразовых глаголов;
- примерное чтение кириллицей на ступенях 0–1 («хэлоу», «сэнк ю»): это грубое приближение, методист должен решить, оставлять ли его;
- естественность английских текстов и соответствие текстов ступеням.

Материалы написаны с нуля для этого приложения. Преподаватель, носитель английского и специалист по казахскому их не проверяли.
